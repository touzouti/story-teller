# Project Overview

This is a web application with a Vue.js frontend and a Go backend. The frontend is built with Vite and uses Tailwind CSS and DaisyUI for styling.

# Building and Running

## Frontend

To run the frontend in development mode:

```bash
cd frontend
npm install
npm run dev
```

To build the frontend:

```bash
cd frontend
npm install
npm run build
```

To preview the frontend build:

```bash
cd frontend
npm run preview
```

## Backend

To run the backend:

```bash
cd backend
go run .
```
